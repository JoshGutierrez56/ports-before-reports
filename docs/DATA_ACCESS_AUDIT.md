# Data access audit

Opened **before bulk acquisition**, 2026-10-15. Source definitions were checked before forecast performance inspection. No paid service, account, API key, cloud resource, access-control workaround or remote write was used. NOAA acquisition belongs to the geospatial pipeline and is reported separately.

## Successful official target

The [BTS freight-indicators dataset](https://data.bts.gov/resource/y5ut-ibwt.json) provides the exact indicator `Loaded Import Containers at Select U.S. Ports in TEUs`; `units=TEUs`, `value1` is quantity, `measure1` is port, and `date` identifies the calendar month. Metadata credits BTS analysis of port-published TEUs and a public-domain US-government license. The selected labels are Los Angeles, Long Beach, NY-NJ and Savannah. Complete extraction contains **336 records: 84 months per authority label, January 2019 through December 2025**. IDs, server counts, uniqueness, direction, status, units and the full port-month grid were checked. LA fractional TEUs were retained. The LA/LB administrative series are non-overlapping port reports, summed only in the gateway target.

The misleadingly named `rd72-aq8r` Monthly TEU Data catalog was inspected and **rejected**: it is an old total-throughput table without a loaded-import split. Its values were never used. The current Monthly TEU dashboard linked from [BTS ports](https://www.bts.gov/ports) was discovered, but its Tableau page returned HTTP 403. The required official fallback `y5ut-ibwt` succeeded; no restriction was bypassed.

## Container-specific PortWatch activity

Official ArcGIS items were resolved and saved, with owner `IMF-portwatch_imf_dataviz`: daily item `83b1bbc7b3354c5fb1f40673bb8f852e` resolves to [Daily_Ports_Data layer 0](https://services9.arcgis.com/weJ1QsnbMYJlCHdG/arcgis/rest/services/Daily_Ports_Data/FeatureServer/0), and ports item `acc668d199d1472abaaf2467133d4ca4` resolves to `PortWatch_ports_database`. The live schema provides `date` as DateOnly and `portcalls_container` as integer counts, distinct from total calls and tonnage fields.

The [official FAQ](https://portwatch.imf.org/pages/faqs), retrieved through its public [page JSON](https://www.arcgis.com/sharing/rest/content/items/640b69a4a96f41a6937cb4d2984f26da/data?f=json), states that the API “allows you to programmatically retrieve daily estimates for ports and chokepoints.” It explicitly describes increasing the record limit and iterating relevant port IDs. This data-specific instruction supports bounded research API extraction; it is not an assumption that the general IMF automated-bulk restriction is absent. [Data and methodology](https://portwatch.imf.org/pages/data-and-methodology) also exposes API and download workflows. Exact page JSON, catalog licenses and response hashes were saved before the long extraction.

The target-matched IDs are **port664 (Los Angeles–Long Beach), port815 (New York–New Jersey), port1170 (Savannah)**. LA/LB is already combined in PortWatch: never add it twice. Names, coordinates, source identifiers and authority reporting definitions were reviewed jointly. NYNJ terminal-boundary equivalence is not proved by its matching name; this is flagged for the frozen exclusion sensitivity. Savannah excludes Brunswick and other GPA locations.

Extraction retrieved **7,671 unique source-object/port-day records**, exactly the server count, covering 2,557 days per gateway in 2019–2025. IDs were enumerated first, fetched in 77 deterministic batches of at most 100, and reconciled exactly. Source counts and editing metadata were unchanged before/after extraction. A preliminary 400-ID GET returned 404 at an overlong query; that response is retained and normal documented requests were reduced to 100 IDs. Transfer-limit flags recursively subdivide batches instead of silently truncating.

Provider-documented blackout dates **2022-05-12, 2023-02-14 and 2024-01-09** produce nine null canonical port-day counts. Original values remain in `source_reported_port_calls` and immutable JSON. Missing coverage is not no traffic. All other observed days are present. Estimated container tonnage is retained with unit `metric_tons_estimated`, never substituted for official TEUs or used in core predictors.

## Vintages and definitions

The FAQ describes weekly publication on Tuesdays at 9 AM ET; OCHA collects weekly on Wednesdays. Daily observations do not imply daily releases. The methodology page records 2024 expansion to five vessel categories, later changes to vessel/port coverage and boundaries, and July 2026 tracked-vessel additions. Container tonnage estimates also use later throughput-calibration changes. This study uses current revised counts under assumed lags, **not verified historical releases**. The older item description defines entry into a port boundary with trade-related filters, while the current FAQ describes berth arrival and bunkering exclusions. This definition evolution is disclosed, not resolved by inventing a fixed historical geofence.

All 336 target first-release timestamps remain null. A dated LA July 2025 cargo release was retained as bounded release-date evidence, but it rounds quantities and does not establish first publication of each precise current-vintage value. Retrieval, file modification and observation dates were not promoted to historical first releases. Modeling assumptions remain 60/90 days after month-end.

## Target cross-checks

`source_target_crosschecks.csv` checks 108 monthly observations. LA 2019 and 2025 HTML tables have separate loaded/empty import/export headers and a calendar-year total: all 24 months and both annual sums match exactly. GPA's official [December 2025 historical PDF](https://gaports.com/wp-content/uploads/2026/02/Monthly-TEU-Throughput-December-2025.pdf) supplies Savannah **Import Full**, 2019–2025. Pages 1–3 were visually inspected with retained page images; the table explicitly says Port of Savannah, TEUs, all terminals, January–December. Of 84 Savannah months, 82 match; BTS is 12 TEUs above this authority vintage in June 2023 and 6 above in December 2020. The original BTS target was retained consistently rather than mixing vintages.

Ten annual comparisons are recorded. LA 2019/2025 and NYNJ 2019 reconcile exactly. NYNJ 2019's [official Trade Statistics PDF](https://www.panynj.gov/content/dam/port/customer-library-pdfs/trade-statistics-2019.pdf), page 3 (printed 4–5), was visually verified to distinguish **import loads 3,770,971 TEUs** from empties, total imports and container counts. Savannah annual-versus-rounded-month sums differ by 0–3 TEUs; the two vintage discrepancies above explain additional differences. No forced equality or fiscal/calendar mixing was applied.

Long Beach's authority archive returned 403 and was not bypassed; BTS's exact loaded-import series remains usable. The NYNJ landing page returned an unrendered shell. Its alternative NY-state official dataset 629s-5a55 has loaded-import TEUs but ends in 2015, so it was rejected for 2019–2025. The authority PDF supplied NYNJ reconciliation. The BTS 2024 annual-report spreadsheet link was discovered but direct download returned 403. These bounded cross-check limitations do not erase the successful exact official target.

## Operational comparator

The 2024 BTS berthing-duration Tableau page returned 403. A separately documented BTS indicator, **Number of Containerships Awaiting Berths at all U.S. Ports**, supplies 102 real records: 51 dates each for LA-LB and Savannah. These are retained in `operational_waiting_stock_2024.parquet`, sourced to MARAD Office of Policy and Plans/Marine Exchange of SoCal. LA-LB includes drift/holding areas; time of day is unspecified; NYNJ is not separately available. These reported containership stocks support descriptive same-date consistency checks, not exact midnight validation of broad NOAA cargo-vessel candidates, a berth-duration substitution, or independent ground truth. They are not forecast features.

## Bounded fallbacks and receipts

The HDX US dataset and its published 42 MB CSV resource were discovered through public CKAN metadata. It uses IMF terms (`Other`, not CC0); original and mirror share one lineage. The datastore preview returned 403. No bypass or bulk mirror download was needed once the documented official API succeeded.

Exact bytes, URLs, resolution, UTC retrievals, HTTP outcomes, attempts, SHA-256, ETag and Last-Modified are in `data/manifests/source_downloads.jsonl` and immutable sidecars. `source_snapshot_catalog.json` enriches query row counts/schema hashes and lineage. `source_flow.json`, `source_targets.json`, coverage tables and cross-check receipts identify curated outputs. `artifacts/audit/source_ledger.jsonl` is append-only. Requests start at no more than one per second per hostname; concurrency was one; retries are at most five. The completed acquisition honored the encountered numeric Retry-After responses. Final downloader hardening also supports HTTP-date Retry-After, does not shorten provider deadlines longer than 60 seconds, and uses exponential backoff with jitter when no valid header exists. One mocked-response test covers HTTP-date, delay-seconds and malformed-header cases; no empirical acquisition was repeated for this change. Failed responses remain evidence, not data. Cached bytes must match hashes. Source tests reject wrong units/status, ambiguous revisions, truncation, duplicate IDs and corrupted cache bytes.
